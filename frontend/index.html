How a case gets settled

No vote count, no mod on call at 2am — just evidence, reasoning, and a verdict that executes itself.

1

File the case

A claim is submitted with its evidence — a PR, a message thread, a delivery log, anything the dispute actually hinges on.

2

Validators reason

Independent LLM validators read the same evidence against the case's stated terms and each reach their own judgment.

3

Consensus resolves

Where validators disagree, GenLayer's Optimistic Democracy settles it into a single outcome using the case's equivalence rule.

4

Verdict executes

Payout releases, a post is restored, or reputation updates — automatically, on-chain, no follow-up vote required.

Built on GenLayer

Verdikt runs on GenLayer's Intelligent Contracts — contracts that can read natural language, pull in outside context, and make non-deterministic calls the way a person would, instead of only executing fixed logic.

Where independent validators would normally disagree, GenLayer's Optimistic Democracy consensus resolves that disagreement into one outcome, using an equivalence principle each case defines up front.
